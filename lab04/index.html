I.

Proceso y problemas

Arme un script en Node con tres comandos: init para generar dos billeteras, status para revisar los UTXOs y el balance de cada una, y send para mandar fondos entre ellas. Al principio se configuro mal el cliente de Electrum, se creo por separado sin pasarle la red, y eso hizo que internamente asumiera mainnet por defecto. Cuando se intento leer las direcciones de testnet, mostraba un error de "invalid prefix", esto se arreglo pasando la red junto con el cliente en la misma configuracion. Despues, cuando se intento realizar la transaccion mostro un error que decia "cannot estimate fee for 1 blocks". Esto sucedia porque el servidor de Electrum de testnet no tiene suficiente actividad en su mempool para auto-estimar la comision pero se logro solucionar fijando un feeRate manual de 2 sat/vB en vez de dejar que el script lo calculara solo. Al final si se lograron generar las billeteras, fondear una desde el faucet, mandar una parte del balance a la otra billetera, y confirmar en el status final como aparecia el UTXO de cambio en mi billetera original junto con el nuevo UTXO recibido en la billetera destino.

II.

Comandos del script

  • initgenera 2 billeteras
  • statusmuestra UTXOs y balance de cada billetera
  • send <satoshis> [feeRate]envía fondos entre billeteras
